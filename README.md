# МЦОЗ — сайт лабораторных анализов

Текущий интерактивный макет сайта Международного центра охраны здоровья: главная, каталог из 1 035 позиций, чекапы, истории, статьи, правовые страницы и адаптивная версия.

## Запуск

Сайт написан на HTML, CSS и JavaScript без сборки и npm-зависимостей. В папке репозитория запустите любой сервер статических файлов, например:

```sh
python -m http.server 8766 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8766/index.html`.

## Структура

- `index.html` — главная страница.
- `catalog.html`, `catalog-data.js`, `catalog.js` — каталог, поиск, фильтры, корзина и подготовка к анализам.
- `catalog-pricing.js` — скидка 30% на 21 участвующий анализ.
- `articles.html`, `article-*.html` — материалы для посетителей.
- `privacy.html`, `consent.html`, `terms.html`, `cookies.html` — правовые страницы макета.
- `assets/` — изображения и логотип.
- `wireframe/`, `specification.html` — материалы просмотра макета, доступные из его верхней панели.
- `build-direct-feed.cjs` — генератор рекламного фида анализов; перед использованием требуется указать актуальный адрес сайта.

## Проверки

При установленном Node.js:

```sh
node audit-site.cjs
node check-privacy.cjs
```

Проверяются ссылки и якоря, уникальность 1 035 позиций, 21 акционная позиция и поведение подключения аналитики.

Загружено в GitHub 28 октября 2026 года. Контент и цены соответствуют сохранённому макету от 12 октября; повторная сверка с прайсом клиники при загрузке в GitHub не проводилась. Указанная в макете акция действует до 30 ноября 2026 года.

Формы демонстрационные: заявки не отправляются, серверный приём обращений не подключён. Корзина хранится в браузере. В `site-config.js` идентификатор Метрики не задан. Страницы закрыты от индексации; правовые тексты требуют заполнения реквизитов и проверки перед боевым запуском.

GitHub Pages включён; репозиторий публичный с разрешения владельца. Обновления ветки main автоматически публикуются после проверок. Пароли и доступы в репозитории не хранятся.
